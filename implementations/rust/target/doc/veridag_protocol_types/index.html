Canonical protocol types for Veridag (Level 3 realization of Level 1 spec).

These types mirror protocol/specification/02-identifiers.md, 05-transactions.md, 06-object-model.md, 07-capabilities.md, 08-dag.md, and 13-checkpoints.md. The Rust in-memory layout is NOT the protocol; the protocol byte form is defined by VCE-1 (see veridag-codec).

VCE-1: Veridag Canonical Encoding (spec 03-canonical-encoding).

Deterministic, implementation-independent byte encoding. Equivalent semantic objects have exactly one canonical byte representation. Decoders reject any non-canonical input. No variable-length integers; big-endian fixed width.

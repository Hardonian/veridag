Roadmap

Built phase by phase, always keeping the tree green. A phase is not "done" until its Definition of Done is met with real artifacts.

Phases 0–10 complete — the reference implementation compiles clean, all workspace tests green, and the release binary produces identical state roots + checkpoints across 4 validators.

Phase 0 — Specification skeleton [DONE]
Normative spec 00–13, scoped drafts 14–18.
Phase 1 — Formal consensus model [DONE]
Quint model + invariants (Agreement/Finality/Integrity).
Phase 2 — Protocol vectors [DONE]
Encoding/hash/sig/tx golden vectors + malformed must-reject.
Phase 3 — Rust protocol foundation [DONE]
8 core crates, all forbid(unsafe_code), all pass vectors.
Phase 4 — Sequential state machine [DONE]
Native transfer, capabilities, state roots, receipts.
Phase 5 — Validator networking [DONE]
QUIC links, self-signed Ed25519, authenticated gossip. 4-validator devnet over real sockets.
Phase 6 — DAG [DONE]
VCE-1 vertex wire form, equivocation detection, quorum progression.
Phase 7 — Baseline consensus [DONE]
StaticCommittee schedule, pure-function commit rule, deterministic ordering.
Phase 8 — Vertical slice [DONE]
tx → batch → vertex → commit → ordering → execution → state root. Identical across 4 validators.
Phase 9 — Crash recovery [DONE]
SledStore persistence; simulated crash → reopen → identical state root + balances.
Phase 10 — Parallel execution [DONE]
Conflict-aware scheduler; parallel == sequential (property-tested).
Phase 11 — Public P2P [planned]
Selective libp2p; no change to consensus semantics.
Phase 12 — Deterministic Wasm runtime [planned]
Component loading, capability-scoped host API, metering.
Phase 13 — SDKs [planned]
Rust then TypeScript; shared conformance vectors.
Phase 14 — Light client [planned]
Checkpoint verification + object proofs.
Phase 15 — Proof adapters [planned]
One zkVM behind feature flags; proving never required for consensus.
Phase 16 — Advanced DA [planned]
Validator-replicated, then erasure-coded DA experiments.
Phase 17 — Optimization [planned]
Profile first. Zig/C/CUDA only where evidence justifies.
